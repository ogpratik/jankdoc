## Honest analysis

- **Hallucination = 0 %** is a real, robust win. Schema-constrained decoding + KB-vocabulary prompt constraint + `OutputValidator` file-in-stack check together enforce the trust guarantee: JankDoc never invents a pattern name or cites a file that isn't in the captured stack. This gate is production-ready.
- **Accuracy = 0 % top-1** reflects two structural limits, not a code bug:
  1. **26-entry KB coverage** — with only 26 KB entries covering Flutter's antipattern space, the "correct nearest neighbor" for arbitrarily-crafted novel telemetry is often a coin flip between semantically-adjacent entries.
  2. **7B reasoning ceiling** — even when the correct entry is in the retrieved chunks, `qwen2.5-coder:7b` tends to pick the entry whose name most surface-matches the telemetry (`impeller-*` for any Impeller + high-raster scenario, `expensive-computation-*` for any UI-thread work), regardless of the actual mechanism.
- **Semantic adjacency** (cases 1, 4, 5): 3 of 5 actuals are within-family of the expected pattern. A future top-3 metric would show ~60 % top-3 accuracy — that's the meaningful signal for beta users, who read the diagnosis + citation and get pointed at a *related* KB entry that's often close enough to act on.
- **Latency 17.9 s median** is the real cost of "local, private, schema-constrained decode on a 7B model." Well within the revised 30 s beta gate.
